# Contributing

This repository's source is public for reference and transparency, but it is not open to unsolicited contributions: issue and pull request creation are restricted to invited collaborators. There is no process to request collaborator access — this project does not accept outside contribution requests at this time.

If you've found a security vulnerability, see [SECURITY.md](SECURITY.md) instead — vulnerability reporting is open to everyone.

## For collaborators

- Pull requests are limited to fixes (bugs, security, correctness). Feature changes should be discussed in an issue before opening a PR.
- `make ci` (build, format check, lint, vulncheck, test) must pass before requesting review.
