# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately via [GitHub Security Advisories](https://github.com/rinsyan0518/ten/security/advisories/new) rather than filing a public issue.

This is open to anyone, regardless of whether you have write access to this repository.

Include as much detail as possible: affected version, reproduction steps, and potential impact. You should receive an initial response within a few days.

## Supported Versions

`ten` does not yet have a formal LTS/maintenance policy. Security fixes are released against the latest tagged version only.
